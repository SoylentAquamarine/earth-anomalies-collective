# SQ-3 — prior-claims catalog, first pass

**Trigger:** this project's own stated parallel-track first task, genuinely unclaimed since bootstrap —
doesn't depend on SQ-1 (the sourcing protocol) being finished first.

## What's already known / not done yet

Already known: the bootstrap scaffolding named four candidate cases from general background knowledge,
explicitly flagged as not yet verified against any real source (per Round 1's own disclosure). Not done:
any actual research into these cases.

## Method and why it's non-circular

Standard WebSearch-then-direct-fetch approach already established across this project family: search
first for an overview, then directly fetch at least one source per case to upgrade past search-synthesis
tier where possible, disclosing which tier each specific claim sits at.

## Honesty precommitment

Report what the sources actually say, including where they correct or complicate the bootstrap
scaffolding's own assumptions — in particular, the scaffolding's framing of the Kazakh Steppe Geoglyphs as
"a genuine, confirmed set of ancient earthworks" turned out to need correction once actually checked (see
below), and that correction is reported here rather than quietly smoothed over.

## Result

Three of the four bootstrap-named candidates researched this pass (Richat Structure deferred — see Scope
below). Full writeup in `data/prior-claims-catalog.md`. Headline results:

- **The Canary Islands "Atlantis grid" (2009)**: directly fetched confirmation that Google's own stated
  explanation (sonar-survey-track artifacts in bathymetric data) is the mainstream account; tabloid origin
  (The Sun) confirmed, not a scientist's claim.
- **The Richat Structure / "Eye of the Sahara"**: search-synthesis tier only this pass (direct fetch of
  the Britannica source blocked, HTTP 403) — geological explanation (a doubly-breached geologic dome,
  not an impact crater) is well-established; Atlantis-linking arguments have specific, named
  counter-objections (imprecise shape match, scholarly consensus that Plato's Atlantis is understood as
  fictional, a mischaracterized "not discovered until the space age" claim actually contradicted by a
  1948 scientific description).
- **The Kazakh Steppe Geoglyphs**: **a real correction to this project's own bootstrap framing.** Directly
  fetched National Geographic coverage: the finder (Dmitriy Dey) is a business manager and satellite-imagery
  enthusiast, not a professional archaeologist; age is only partially confirmed (OSL dating places two
  specific sites at 800 BC and 750 BC, "accurate within 20 years") while Dey's own much older 8,000-year
  estimate is disputed by the actual excavating team; the findings were **not yet peer-reviewed** as of
  the fetched article; one outside archaeologist (Michael Frachetti) is quoted calling a related claim
  "not necessarily wrong" but stating "it just doesn't qualify as science."

## Decision

The Kazakh Steppe Geoglyphs case is **not** the clean "genuine anomaly-turned-confirmed-finding" contrast
case the bootstrap scaffolding assumed — it's actually a good illustration of this project's own evidence
ladder in action: real features, partial and disputed dating, pre-peer-review status. This is arguably a
*better* calibration case than originally thought, precisely because it shows a real, ongoing, honestly
uncertain scientific process rather than a settled yes/no.

## Scope and limitations, disclosed

The Richat Structure entry stays at search-synthesis tier (direct fetch blocked); the Antarctica
pyramid/base claims named in the bootstrap scaffolding were not researched this pass — left for a future
cycle. This catalog should not yet be treated as covering its own originally-scoped candidate list
completely.
